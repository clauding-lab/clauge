# Clauge Release Checklist

## Known issues

- **Tray icon is colored (not monochrome template).** The current `src-tauri/icons/tray-icon.png` and `tray-icon@2x.png` were generated by downscaling the colored 1024×1024 app icon via `sips`. macOS expects menu-bar tray icons to be **template images** — flat black-on-transparent, with the system applying tint based on light/dark menu-bar appearance. Replace with a true monochrome rendering before public release. The source `docs/design/assets/clauge-menubar.svg` exists but uses multiple stroke colors (`#d97757`, `#6a9bcc`, `#faf9f5`) and would need a single-color variant authored before rasterizing.
