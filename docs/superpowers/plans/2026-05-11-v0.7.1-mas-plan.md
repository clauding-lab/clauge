# v0.7.1 Mac App Store Flavor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Clauge v0.7.1 with a sandboxed Mac App Store-flavor build alongside the existing DMG flavor (from v0.7.0). The MAS flavor adds: a `mas` Cargo feature flag, a sandbox entitlements file, a security-scoped bookmark for `~/.claude/projects/` JSONL access, a "Check for Updates" → MAS Store redirect, a first-launch grant banner, and a 4th Settings → Connections row. Final step is App Store Connect submission and waiting for Apple review.

**Architecture:** Builds on the v0.7.0 hybrid-auth architecture (`keychain.rs`, `anthropic_oauth.rs`, `claude_ai_session.rs`, `connections.rs`) which is **already shipped in v0.7.0**. v0.7.1 adds `security_scoped_bookmark.rs` (cfg-gated to `feature = "mas"`), a `tauri.mas.conf.json` overlay, and a new CI matrix row. Both DMG (v0.7.0) and MAS (v0.7.1) flavors are produced from the same source tree.

**Tech Stack:** Rust 1.95 + Tauri 2.x (already in v0.7.0), `objc2-foundation` (NSOpenPanel + NSURL bookmarks — new in v0.7.1), App Store Connect + Transporter (submission), GitHub Actions matrix (third runner row).

**Reference spec:** `docs/superpowers/specs/2026-05-11-v0.7.1-mas-design.md`

**Depends on:** v0.7.0 (DMG-only) shipped per `docs/superpowers/plans/2026-05-11-v0.7.0-dmg-plan.md`. v0.7.1 cannot start until v0.7.0's hybrid-auth modules are in main and validated in production.

**Supersedes:** the MAS-related portions of `docs/superpowers/plans/2026-05-09-v0.7.0-mas-plan.md` (combined DMG+MAS plan). Per the 2026-05-11 re-sequencing decision (saved in project memory `project_release_sequencing.md`), MAS work is split into this separate v0.7.1 cycle to remove Apple-review risk from v0.7.0's critical path.

**Sequencing:** Parallel side workstream to v0.6.0 (Windows port). MAS-flavor build infrastructure + Apple submission begin once v0.7.0 has shipped on the DMG side. Apple review (1-4 weeks) doesn't gate engineering — v0.7.1 ships when Apple approves the listing.

**Important:** several Apple-side artifacts (App Store Connect listing, Apple Review verdict on the cross-app keychain entitlement) are unknown until the implementation actually runs. Tasks marked ⚠ require empirical verification at execution time and may need plan adjustments based on findings.

```rust
//! Security-scoped bookmark for ~/.claude/projects/ access in the MAS flavor.
//!
//! macOS App Sandbox blocks reading another app's data folder by default.
//! NSURL bookmark APIs let the user grant a one-time, persistent, read-only
//! access via NSOpenPanel. The bookmark blob persists across app launches
//! in Tauri's store.
//!
//! Only compiled in the MAS build (cfg(feature = "mas")). The DMG flavor
//! continues to read filesystem directly.

#![cfg(feature = "mas")]

use objc2::rc::Retained;
use objc2_foundation::{NSData, NSError, NSString, NSURL};

const STORE_KEY: &str = "claude_projects_bookmark";

#[derive(Debug, thiserror::Error)]
pub enum BookmarkError {
    #[error("NSOpenPanel cancelled or failed")]
    PanelCancelled,
    #[error("bookmark resolution failed (stale)")]
    Stale,
    #[error("Tauri store error: {0}")]
    Store(String),
    #[error("foundation error: {0}")]
    Foundation(String),
}

/// Show NSOpenPanel; user picks a folder; capture NSURL → bookmark blob → persist.
pub async fn prompt_for_folder_grant(
    app: &tauri::AppHandle,
) -> Result<(), BookmarkError> {
    use tauri_plugin_dialog::DialogExt;

    // Use Tauri's dialog plugin. Note: in MAS sandbox, this triggers NSOpenPanel
    // with the user-selected security scope. Tauri 2.x dialog plugin should
    // honor the security scope on macOS — verify at execution time.
    let folder = app
        .dialog()
        .file()
        .set_title("Choose your Claude Code logs folder")
        .set_directory(home_default_claude_dir())
        .blocking_pick_folder();

    let path = folder.ok_or(BookmarkError::PanelCancelled)?;
    let path_str = path.to_string();

    // Convert path → NSURL → bookmark data with security scope.
    let nsurl = unsafe {
        let ns_path = NSString::from_str(&path_str);
        NSURL::fileURLWithPath(&ns_path)
    };

    let bookmark_data = unsafe {
        // .withSecurityScope = 0x0800
        const NS_URL_BOOKMARK_CREATION_WITH_SECURITY_SCOPE: usize = 0x0800;
        let mut error: Option<Retained<NSError>> = None;
        let data = nsurl.bookmarkDataWithOptions_includingResourceValuesForKeys_relativeToURL_error(
            NS_URL_BOOKMARK_CREATION_WITH_SECURITY_SCOPE,
            None,
            None,
            Some(&mut error),
        );
        data.ok_or_else(|| {
            BookmarkError::Foundation(format!("bookmark create failed: {:?}", error))
        })?
    };

    // Serialize NSData → Vec<u8> → store in Tauri store.
    let bytes: Vec<u8> = unsafe {
        let len = bookmark_data.length();
        let ptr = bookmark_data.bytes() as *const u8;
        std::slice::from_raw_parts(ptr, len).to_vec()
    };

    use tauri_plugin_store::StoreExt;
    let store = app.store("settings.json").map_err(|e| BookmarkError::Store(e.to_string()))?;
    store.set(STORE_KEY, serde_json::Value::Array(
        bytes.iter().map(|b| serde_json::Value::Number((*b).into())).collect()
    ));
    store.save().map_err(|e| BookmarkError::Store(e.to_string()))?;

    Ok(())
}

/// Resolve persisted bookmark; call f with the security-scoped path; clean up.
/// Returns Stale if bookmark resolution fails (user must re-grant).
pub fn with_scoped_path<F, T>(
    app: &tauri::AppHandle,
    f: F,
) -> Result<T, BookmarkError>
where
    F: FnOnce(&str) -> T,
{
    use tauri_plugin_store::StoreExt;
    let store = app.store("settings.json").map_err(|e| BookmarkError::Store(e.to_string()))?;
    let blob = store.get(STORE_KEY).ok_or(BookmarkError::Stale)?;
    let bytes: Vec<u8> = blob
        .as_array()
        .ok_or(BookmarkError::Stale)?
        .iter()
        .filter_map(|v| v.as_u64().map(|n| n as u8))
        .collect();

    unsafe {
        let nsdata = NSData::with_bytes(&bytes);
        // .withSecurityScope = 0x0400
        const NS_URL_BOOKMARK_RESOLUTION_WITH_SECURITY_SCOPE: usize = 0x0400;
        let mut error: Option<Retained<NSError>> = None;
        let mut is_stale: bool = false;

        let url = NSURL::URLByResolvingBookmarkData_options_relativeToURL_bookmarkDataIsStale_error(
            &nsdata,
            NS_URL_BOOKMARK_RESOLUTION_WITH_SECURITY_SCOPE,
            None,
            &mut is_stale,
            Some(&mut error),
        ).ok_or(BookmarkError::Stale)?;

        if is_stale {
            return Err(BookmarkError::Stale);
        }

        let started = url.startAccessingSecurityScopedResource();
        if !started {
            return Err(BookmarkError::Stale);
        }

        let path_ns: Retained<NSString> = url.path().ok_or(BookmarkError::Stale)?;
        let path_str = path_ns.to_string();
        let result = f(&path_str);

        url.stopAccessingSecurityScopedResource();
        Ok(result)
    }
}

fn home_default_claude_dir() -> std::path::PathBuf {
    std::env::var("HOME")
        .map(|h| std::path::PathBuf::from(h).join(".claude").join("projects"))
        .unwrap_or_else(|_| std::path::PathBuf::from("/"))
}

pub fn has_bookmark(app: &tauri::AppHandle) -> bool {
    use tauri_plugin_store::StoreExt;
    let Ok(store) = app.store("settings.json") else { return false; };
    store.get(STORE_KEY).is_some()
}

pub fn clear_bookmark(app: &tauri::AppHandle) -> Result<(), BookmarkError> {
    use tauri_plugin_store::StoreExt;
    let store = app.store("settings.json").map_err(|e| BookmarkError::Store(e.to_string()))?;
    store.delete(STORE_KEY);
    store.save().map_err(|e| BookmarkError::Store(e.to_string()))?;
    Ok(())
}
```

Note on the `objc2-foundation` API surface: the exact method names and signatures (`bookmarkDataWithOptions_…`, `URLByResolvingBookmarkData_…`) follow Apple's Objective-C convention with underscores between argument labels. Tauri 2.x's `objc2-foundation` 0.3 should support these. **Verify at execution time** that the signatures match — Apple's NSURL bookmark API has been stable for ~10 years but objc2 binding details may have evolved.

```rust
let claude_dir = {
    #[cfg(feature = "mas")]
    {
        // Use security-scoped bookmark; fall through to env var if no bookmark yet.
        match crate::security_scoped_bookmark::with_scoped_path(&app, |p| p.to_string()) {
            Ok(path) => path,
            Err(_) => std::env::var("HOME")

        }
    }

    }

cmd.env("CLAUDE_DIR", &claude_dir);
```

⚠ Note: `with_scoped_path` calls `start/stop AccessingSecurityScopedResource` synchronously around the closure. That's fine for reading the path string, but the SEA sidecar process needs filesystem access for its full lifetime. The bookmark must remain "started" while the sidecar runs — refactor to call `start` once at sidecar-spawn time and `stop` when sidecar exits, OR pass the bookmark blob to the sidecar and have it resolve scoped access in-process. **Pick one approach during implementation; manual smoke verifies the chosen approach works.**

The cleanest approach is likely: spawn a long-lived goroutine in Rust that holds the security-scoped resource, and the sidecar reads via the resolved path. Document the exact mechanism in the commit message.

```javascript
async function refreshJsonlBanner() {
```
