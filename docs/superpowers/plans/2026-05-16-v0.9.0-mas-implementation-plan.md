# v0.9.0 MAS FLAVOR — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Per `feedback_subagent_model.md`, **all subagent dispatches must use Opus.**

**Goal:** Ship Clauge v0.9.0 — a sandboxed Mac App Store flavor alongside the existing DMG (Mac) and NSIS (Windows) flavors. Distributes through the Mac App Store via Apple Developer ID signing, runs inside the App Sandbox with a single user-granted security-scoped bookmark for `~/.claude/`, uses the filesystem credential reader (no cross-app keychain entitlement requested), replaces the Tauri auto-updater with an App Store storefront redirect.

**Architecture:** Rust `mas` Cargo feature flag gates the MAS-only code paths. Three-flavor CI matrix produces DMG + NSIS + MAS artifacts from one git tag. Wizard step 2 swaps Permissions/Keychain copy for Grant-folder copy on MAS; wizard step 5 swaps "macOS Keychain prompt" copy for "reads from folder you granted in step 2." Settings → Connections gets a 4th row showing bookmark state. Engineering merges to main; Apple App Store submission is a calendar-driven side workstream (Apple Review 1–4 weeks).

**Tech Stack:** Tauri 2.x shell, vanilla JS frontend, Node.js sidecar with Hono, `objc2-foundation` 0.3.2 for NSURL bookmark APIs. Same baseline as v0.8.2.

**Reference spec:** `docs/superpowers/specs/2026-05-16-v0.9.0-mas-design.md` (at commit `34b041b` — post-review refinement).

//!
//! Apple's App Sandbox forbids reading another app's data folder
//! (~/.claude/, written by Claude Code CLI) without an explicit user grant
//! via the user-selected file entitlement family. This module wraps NSURL's

//!   2. Persist a security-scoped bookmark blob to the Tauri store

//!

use objc2_foundation::{NSURL, NSData /* NSURLBookmarkCreationOptions, NSURLBookmarkResolutionOptions */};
use std::path::PathBuf;
use std::sync::OnceLock;
use tauri::{AppHandle, Manager};

/// Process-wide cache for the resolved ~/.claude/ path. Populated by
/// `sidecar::spawn_and_supervise` on supervisor start (which calls
/// `acquire_scoped_path` and holds the returned `ScopedHandle` for the
/// loop's lifetime). Read by `keychain::read_claude_code_credentials`'s

/// in its signature — preserves the `keychain_cache::ReaderFn` zero-arg
/// closure type intact.
pub static MAS_CLAUDE_DIR: OnceLock<PathBuf> = OnceLock::new();

/// Tauri store key for the persisted bookmark blob.

#[derive(Debug, thiserror::Error)]
pub enum BookmarkError {
    #[error("no bookmark blob in store — user hasn't granted folder access yet")]
    NoBookmark,
    #[error("bookmark blob resolution failed: {0}")]
    Resolution(String),
    #[error("startAccessingSecurityScopedResource returned false")]
    ScopeStart,
    #[error("NSOpenPanel returned no selection (user cancelled)")]
    UserCancelled,
    #[error("tauri store error: {0}")]
    Store(String),
}

/// RAII guard that calls `stopAccessingSecurityScopedResource()` on Drop.
/// Hold for the entire duration the path needs to be accessible.
pub struct ScopedHandle {
    url: objc2::rc::Retained<NSURL>,
}

impl Drop for ScopedHandle {
    fn drop(&mut self) {
        unsafe {
            // Safety: NSURL.stopAccessingSecurityScopedResource is callable on
            // any NSURL that was previously the receiver of a successful
            // startAccessingSecurityScopedResource call. If start returned
            // false (ScopeStart error), we never created a ScopedHandle, so
            // this Drop only fires when start succeeded.
            self.url.stopAccessingSecurityScopedResource();
        }
    }
}

#[cfg(all(target_os = "macos", feature = "mas"))]
fn read_from_path_unix(path: &std::path::Path) -> Result<ClaudeCodeCreds, KeychainError> {
    let blob = std::fs::read(path).map_err(|e| match e.kind() {
        std::io::ErrorKind::NotFound => KeychainError::NotFound,
        std::io::ErrorKind::PermissionDenied => KeychainError::AccessDenied,
