**Goal:** Ship Clauge v0.7.3 as a focused auto-update reliability hotfix: new `restart_app` IPC + Settings → Updates "Restart Now" button + cold-launch self-heal in `port_discovery::discover` that detects and kills orphan sidecars from previous versions.

**Architecture:** Two new helpers + one new IPC + one frontend button. `port_discovery::discover` extended to query `/api/health` on the External path and version-check against `env!("CARGO_PKG_VERSION")`; on mismatch, lsof+kill the orphan and retry. `restart_app` IPC drains AppState::children, kills them, sleeps 200 ms, then `app.restart()`. No new dependencies.

**Tech Stack:** Rust 1.95 + Tauri 2.x, `tokio::process::Command` for lsof+kill shell-outs, `serde_json` for /api/health body parsing (already a dep), HTML/CSS/vanilla JS (no React/framework).

**Reference spec:** `docs/superpowers/specs/2026-05-15-v0.7.3-design.md`

**Sequencing:** v0.7.2 (shipped 2026-05-15) → **v0.7.3 (this plan)** → v0.8.0 MAS-flavor + Apple Developer ID signing + Architecture A data plumbing.

**Important — what's empirical here:**
- The orphan-sidecar bug was empirically observed during v0.7.2 release smoke. The user installed v0.7.2 from a local DMG, observed Settings → version still showed 0.7.1, ran `pkill -f clauge-server` to force-kill the orphan, and re-launching then surfaced the correct version. The bug is real and reproducible with any cross-version restart that fails to take down the sidecar.
- `lsof -i :PORT -t` is part of the macOS base install (`/usr/sbin/lsof`). The plan assumes its presence; the implementation logs warn and falls through if it's missing.
- Tauri 2's `app.restart()` is documented as a stable in-place process replacement that calls `std::process::exit(0)` and re-execs the binary path. We rely on this — no fallback needed.

```rust
/// Compare a `/api/health` response body's `version` field to the Tauri
/// shell's compile-time version. Returns `true` iff the body parses, has a
/// `version` string field, and that field exactly equals
/// `env!("CARGO_PKG_VERSION")`.
///
/// Three failure modes (malformed JSON, missing field, mismatched value)
/// all return `false`. The compile-time `env!` guarantees the comparison
/// is against THIS Tauri shell's version, not whatever the running sidecar
/// claims to be.
fn version_matches_self(health_response: &str) -> bool {
    let v: serde_json::Value = match serde_json::from_str(health_response) {
        Ok(v) => v,
        Err(_) => return false,
    };
    let server_version = match v.get("version").and_then(|v| v.as_str()) {
        Some(s) => s,
        None => return false,
    };
    server_version == env!("CARGO_PKG_VERSION")
}
```

```rust
/// Find any PIDs listening on the given TCP port and kill them with SIGKILL.
///
/// Shells out to `lsof -i :PORT -t` (one PID per line, no extra columns)
/// then runs `kill -9 PID` for each. If `lsof` is missing or fails to
/// spawn (returns Err), the caller decides whether to retry discovery
/// or fall through. Failures from `kill` (process already dead, owned by
/// another user) are silently ignored — the post-condition is "port is
/// free", and we tolerate races where the process exited on its own.
///
/// Sleeps 300 ms after the kill attempts to let the OS release the port.
async fn kill_pid_on_port(port: u16) -> Result<(), String> {
    use tokio::process::Command;
    let lsof = Command::new("lsof")
        .args(["-i", &format!(":{}", port), "-t"])
        .output()
        .await
        .map_err(|e| format!("lsof spawn failed: {}", e))?;
    let stdout = std::str::from_utf8(&lsof.stdout).unwrap_or("");
    let pids: Vec<&str> = stdout.split_whitespace().collect();
    if pids.is_empty() {
        return Ok(());
    }
    for pid in pids {
        log::info!("kill_pid_on_port: SIGKILL pid={} on port={}", pid, port);
        let _ = Command::new("kill").args(["-9", pid]).status().await;
    }
    tokio::time::sleep(Duration::from_millis(300)).await;
    Ok(())
}
```

```rust
/// Same probe as `probe()`, but returns the response body string when the
/// service identifies as "clauge" so callers can parse additional fields
/// (e.g., the `version` field for cold-launch self-heal). Returns `None`
/// on any failure mode `probe` would have returned `false` for.
///
/// We re-parse the body in `version_matches_self` rather than taking the
/// already-parsed `HealthBody`; the cost is one extra JSON parse, but the
/// helper stays a pure function that accepts any string for unit testing.
async fn probe_with_body(port: u16) -> Option<String> {
    let url = format!("http://127.0.0.1:{}/api/health", port);
    let client = reqwest::Client::builder()
        .timeout(Duration::from_secs(1))
        .build()
        .ok()?;
    let resp = client.get(&url).send().await.ok()?;
    if !resp.status().is_success() {
        return None;
    }
    let text = resp.text().await.ok()?;
    let parsed: HealthBody = serde_json::from_str(&text).ok()?;
    if parsed.service != "clauge" {
        return None;
    }
    Some(text)
}
```

- [ ] **Step 5: Replace `discover` to use the new helpers**

In `src-tauri/src/port_discovery.rs`, replace the existing `discover` function (lines 42-48) with the two-function form:

```rust
pub async fn discover() -> DiscoveryResult {
    discover_with_retry(true).await
}

/// Inner discovery loop with a retry budget for orphan-sidecar eviction.
///
/// First call is `discover_with_retry(true)`. If we find an existing sidecar
/// whose `/api/health` reports a version that mismatches our compile-time
/// `CARGO_PKG_VERSION`, we kill the PID listening on port 3456 and re-run
/// ourselves with `false`. The second call falls through to `SpawnAt` even
/// if the orphan is still alive (the supervisor's bind will fail and the
/// crash-respawn-backoff handles it). This bounded recursion guarantees
/// termination even if `lsof` is missing.
async fn discover_with_retry(allow_orphan_kill: bool) -> DiscoveryResult {
    if let Some(body) = probe_with_body(3456).await {
        if version_matches_self(&body) {
            return DiscoveryResult::External(3456);
        }
        log::warn!(
            "Orphan sidecar detected on port 3456: version mismatch (self={})",
            env!("CARGO_PKG_VERSION")
        );
        if allow_orphan_kill {
            if let Err(e) = kill_pid_on_port(3456).await {
                log::warn!("kill_pid_on_port failed: {} — falling through to SpawnAt", e);
            }
            return Box::pin(discover_with_retry(false)).await;
        }
        log::warn!(
            "Orphan kill already attempted; falling through to SpawnAt — supervisor backoff will handle"
        );
    }
    DiscoveryResult::SpawnAt(3456)
}
```

(`Box::pin` is required because async recursion in Rust needs an explicit indirection — the future can't be Sized otherwise.)

```rust
/// Restart the Tauri shell after killing all sidecar children.
///
/// Used by the Settings → Updates "Restart Now" button after a successful
/// `check_for_updates` install. Sequence:
/// 1. signal_shutdown() — sets the shutting_down flag and notifies waiters
///    so the supervisor in sidecar.rs exits its loop without respawning.
/// 2. take_all_children() + kill — drops the live sidecar process.
///    SIGKILL on a CommandChild we own; failures are logged.
/// 3. sleep 200 ms — gives SIGKILL time to deliver before the process
///    replaces itself.
/// 4. app.restart() — Tauri's stable in-place re-exec. Does not return.
///
/// On macOS, app.restart() exec()s the binary path of the current .app
/// bundle. After an auto-update has replaced /Applications/Clauge.app,
/// the new process loads the new binary AND the new sidecar binary
/// (because port_discovery's SpawnAt path will spawn a fresh child).
#[tauri::command]
pub async fn restart_app(
    state: State<'_, AppState>,
    app: tauri::AppHandle,
) -> Result<(), String> {
    state.signal_shutdown();
    for child in state.take_all_children() {
        let pid = child.pid();
        if let Err(e) = child.kill() {
            log::warn!("restart_app: failed to kill sidecar pid={}: {}", pid, e);
        } else {
            log::info!("restart_app: killed sidecar pid={}", pid);
        }
    }
    tokio::time::sleep(std::time::Duration::from_millis(200)).await;
    app.restart();
}
```

```js
      checkBtn.disabled = true;

        const result = await window.__TAURI__.core.invoke('check_for_updates');
        if (result?.status === 'installed') {

        }
      } catch (err) {

        if (statusEl) statusEl.textContent = 'Check failed (see console)';
      } finally {
        checkBtn.disabled = false;
      }

      window.__TAURI__.core.invoke('restart_app').catch((err) => {
        // Should never reach: app.restart() doesn't return a Result.
```

```markdown
**Auto-update reliability hotfix.** Fixes orphan sidecar persistence across auto-updates and adds an in-app "Restart Now" button.

## Fixed

- **Orphan sidecar across auto-updates.** Previous versions could leave an old `clauge-server` sidecar process running on port 3456 across the user's restart, causing the new Tauri shell to use the orphan as its sidecar and serve the OLD `package.json` version. v0.7.3 adds cold-launch self-heal: if `port_discovery` finds an existing sidecar whose `/api/health.version` doesn't match the Tauri shell's compile-time version, it `lsof -i :3456 -t` + `kill -9` the orphan and respawns a fresh child.
- **No in-app "Restart Now" affordance.** Settings → Updates → Check Now used to install the update silently and rely on the user noticing a macOS notification. v0.7.3 surfaces a prominent "↻ Restart Now to apply v0.7.3" button after install, in the same pane as Check Now.

## Added

- `restart_app` IPC command (kills children + Tauri's in-place re-exec).

## Internal

- `port_discovery::version_matches_self` and `kill_pid_on_port` helpers.
- `port_discovery::discover` split into `discover` + `discover_with_retry` (bounded recursion).
- `UpdateStatus::Installed { version }` payload extension.
- v0.7.2 plan Task 17 lessons-learned addendum on local-build sidecar rebuild requirement.

## How to upgrade

- **From v0.7.2 (auto-update):** Open Clauge → Settings → Updates → click "Check Now" → click the new "Restart Now" button when it appears.
- **From v0.7.0 / v0.7.1 (stuck on broken updater UI):** download `Clauge_0.7.3_universal.dmg` from this release page and drag-install over `/Applications/Clauge.app`.
- **Fresh install:** Download `Clauge_0.7.3_universal.dmg`, drag `Clauge.app` to `/Applications/`, launch. The first-launch wizard will walk you through Keychain access.

## Known limitations
```
