# Clauge v0.9.5 Implementation Plan — cleanup release

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.9.5 as a pure cleanup release containing three independent housekeeping items: (a) commit the staged `AGENTS.md` landmines #17/#18/#19 (already drafted on disk), (b) B.6 partial migration of raw `__TAURI__.core.invoke()` calls to `ClaugeBridge.*` in `connections.js`, `app.js`, and `popover/splash.js`, and (c) B.1 migration of remaining inline user-facing strings in popover code to the existing `copy.json` registry. **Tech stack:** Vanilla JS (popover + dashboard) using existing facades — `popover/lib/copy.js` for string lookups, `popover/lib/tauri-bridge.js` for IPC, both classic-script loaded before consumers.

**Predecessor:** `docs/superpowers/specs/2026-05-26-v0.9.5-batch1-design.md` is now **OBSOLETE** — its wizard step and `onboarding.js` invoke migration moved to the v0.10.0 plan. Only the AGENTS.md commit from that spec ships here. Delete the obsolete batch-1 spec after this PR merges.

- [ ] **Step 2: Pattern — adding the DOM helper (if needed)**

Append to `popover/lib/copy.js`:

```javascript
  /**
   * Apply copy registry to DOM: walks all [data-copy] elements and sets
   * their textContent. For elements with [data-copy-attr="title"] etc.,
   * sets that attribute instead of textContent. Call after window.__claugeCopyReady.
   */
  function applyDomCopy(root) {
    const scope = root || document;
    scope.querySelectorAll('[data-copy]').forEach((el) => {
      const key = el.getAttribute('data-copy');
      const target = el.getAttribute('data-copy-attr') || 'textContent';
      const value = window.t(key);
      if (target === 'textContent') el.textContent = value;
      else el.setAttribute(target, value);
    });
  }

  if (typeof window !== 'undefined') {
    window.applyDomCopy = applyDomCopy;
  }
```

In `popover/popover.js`, after `window.__claugeCopyReady` resolves, call:
```javascript
window.applyDomCopy();
```
