Clauge

v0.4.0 · MIT · clauding-lab

Token analytics and subscription value dashboard for Claude Code and claude.ai. Local Node + HTML, npx-installable. Browser extension auto-syncs claude.ai plan usage.

GitHub repository→ Changelog→ Report an issue→

What it does

  • Per-session trackingTokens · cost · model · cache · primary task type
  • Per-project rollupCost · sessions · messages · tools · hit %
  • Cache analyticsNet savings · 5m vs 1h tier separation
  • Plan tracking5h, 7d, Sonnet, Design rings
  • Task classificationCoding · debug · test · plan · git ops · build
  • API replacement valueHonest framing · observed token usage
