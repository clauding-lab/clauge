Enable claude.ai auto-sync

One-time setup. The extension polls your already-authenticated claude.ai tab every minute and feeds usage back here automatically.

Install Clauge Sync extension see install options below

Works on Chrome, Edge, Brave, Arc, and Vivaldi. Make sure you're signed in to claude.ai in the same browser profile.

Other ways to sync

Developer-mode install (no Chrome Web Store needed)

  1. Clone or download github.com/clauding-lab/clauge
  2. Open chrome://extensions and toggle Developer mode
  3. Click Load unpacked and pick the extension/ folder

One-shot bookmarklet (no extension)

Drag Sync Clauge to your bookmarks bar, open claude.ai, and click the bookmark whenever you want a fresh snapshot.
