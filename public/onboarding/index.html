Welcome to Clauge

Clauge tracks your Claude Code and claude.ai usage from the menu bar.

Let's set up access in a few quick steps.

macOS Keychain Access

Next, macOS will ask permission to read your Claude Code credentials. When you see this dialog:

Clauge wants to use your confidential information stored in "Claude Code-credentials" in your keychain.

↑ click this one

Heads up: until Clauge ships with Apple Developer signing, this prompt may reappear on each launch. Always click "Always Allow" when you see it.

Reading Your Credentials

Next, Clauge will read your Claude Code credentials from your user profile:

%USERPROFILE%\.claude\.credentials.json

This is the file Claude Code's CLI writes when you run claude /login. No prompt — just a silent file read.

Heads up: if you haven't logged in to Claude Code yet, open a terminal and run claude /login first. Clauge can't read what isn't there.

Other Settings

  • Notifications

    Clauge will notify you when updates are available. Click "Allow" when macOS asks.

    Clauge will notify you when updates are available via Windows notifications.

  • Launch at Login

    Clauge has been added to your login items so it starts when you log in to your Mac. Toggle off in System Settings → General → Login Items if you'd prefer manual launches.

    Clauge has been added to your startup apps so it starts when you sign in to Windows. Toggle off in Settings → Apps → Startup if you'd prefer manual launches.

  • claude.ai sign-in

    Optional. Connect from Settings → Connections if you have a claude.ai account (separate from Claude Code).

    Not yet supported on Windows — coming in a future release. Claude Code CLI credentials are enough for most usage.

Ready to Connect

Clicking Connect will trigger the macOS Keychain prompt.

Remember: click "Always Allow" when you see it.

Clicking Connect will read your Claude Code credentials and open the dashboard.
